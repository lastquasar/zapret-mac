# zapret-mac

Приложение для macOS, которое открывает **YouTube и Discord** (включая голосовые каналы).
В интерфейсе одна кнопка — «Включить». Настройки обхода приложение подбирает само.

Идея и списки доменов — из [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) (Windows).
Здесь та же задача решена для Mac.

- Только Apple Silicon (M1 и новее), macOS 14 Sonoma и новее.
- Приложение не подписано сертификатом Apple — при первом запуске нужно разрешить его вручную (см. ниже).

## Установка

1. Скачайте `zapret_alex_arbuz.dmg` со страницы [Releases](../../releases).
2. Откройте DMG и перетащите приложение в папку «Программы».
3. Дважды щёлкните приложение в «Программах». macOS скажет, что не может его проверить — нажмите «Готово».
4. Откройте «Системные настройки» → «Конфиденциальность и безопасность», прокрутите вниз и нажмите «Всё равно открыть».
5. Нажмите большую кнопку и введите пароль от Mac. Пароль нужен один раз — для установки помощника, который настраивает сеть.

После этого приложение живёт в строке меню (значок щита) и запускается при входе в систему.

Удаление: значок щита → шестерёнка → «Удалить…», потом перетащите приложение в Корзину.

## Как это работает

```
приложения ──► utun225 (tun2socks) ──► ciadpi (ByeDPI, SOCKS5 :10800) ──► en0 ──► интернет
DNS:  macOS ──► 127.0.0.1:53 ──► DNS-over-HTTPS (1.1.1.1 / 8.8.8.8 / 9.9.9.9)
```

- **tun2socks** забирает весь IPv4-трафик через маршруты `0/1` и `128/1`, включая UDP.
- **ciadpi** ([ByeDPI](https://github.com/hufrea/byedpi) с патчем для macOS) применяет обход:
  - TCP — только к доменам из списков Flowseal и встроенным доменам YouTube/Discord, остальные сайты идут без изменений;
  - UDP — поддельные пакеты на порты голоса Discord (`50000-50100`, `19294-19344`) и QUIC (`443`), как в `general.bat`.
- **DNS** идёт через DoH, поэтому провайдер не может подменить ответы. На AAAA- и HTTPS-запросы ответ пустой — весь трафик идёт по IPv4.
- **Помощник** `zapret-helper` работает от root как LaunchDaemon `local.zapret.helper`. Приложение говорит с ним через `/var/run/zapret.sock`.
- **Автоподбор**: 12 стратегий проверяются по 4 параллельно на запасных портах. Проверки: youtube.com, googlevideo, ytimg, discord.com, API, gateway, CDN, сервер обновлений Discord.
- **Фон**: каждые 30 секунд проверка интернета через TUN, каждые 5 минут — YouTube и Discord (две неудачи подряд → новый подбор), раз в сутки обновление списков с GitHub. Если через TUN интернет пропал, приложение возвращает обычную сеть и пробует снова через 5 минут.

### Патч ByeDPI

`patches/byedpi-macos.patch`:

- исходящие сокеты привязываются к физическому интерфейсу (`CIADPI_BOUND_IF` → `IP_BOUND_IF`), иначе трафик зациклится в TUN;
- исправлено сравнение диапазонов портов (`--pf`) — порты сравнивались в сетевом порядке байт.

Чтобы привязанные сокеты не упирались в маршруты TUN, помощник добавляет такие же маршруты `0/1` и `128/1` со scope физического интерфейса через роутер.

## Сборка

Нужны Xcode и Go (`brew install go`).

```bash
./build.sh
```

Результат: `build/zapret_alex_arbuz.app` и `build/zapret_alex_arbuz.dmg`.
Свою картинку для иконки можно передать так: `ICON=path/to/picture.png ./build.sh`.

## Файлы после установки

| Путь | Что это |
|---|---|
| `/Library/Application Support/Zapret/` | помощник, ciadpi, tun2socks, списки, состояние |
| `/Library/LaunchDaemons/local.zapret.helper.plist` | автозапуск помощника |
| `/Library/Logs/Zapret/helper.log` | журнал |

Если что-то не работает: шестерёнка → «Сохранить отчёт на Рабочий стол». В отчёте есть статус, маршруты и журнал.

## Тесты

- `Tests/smoke` — DNS-прокси на порту 15353 и все стратегии через ciadpi, без root:
  ```bash
  swiftc -O -target arm64-apple-macos14 Sources/Shared/*.swift $(ls Sources/Helper/*.swift | grep -v main.swift) Tests/smoke/main.swift -o build/smoke && ./build/smoke "$PWD/vendor"
  ```
- `Tests/render` — рисует окна приложения в PNG (собирается с `-D PREVIEW`).

## Ограничения

- macOS не даёт ByeDPI отправлять TCP-фейки (`--fake`), поэтому стратегии — только split/disorder/oob/tlsrec. Если у вашего провайдера ни одна не работает, приложение скажет об этом.
- Если включён другой VPN, приложение покажет предупреждение — два VPN мешают друг другу.
- Работает только IPv4.
